# Material Property Prediction using Machine Learning

## Quick Start

```
# 1. Install dependencies
pip install -r requirements.txt

# 2. Place datasets in data\raw\
#    - Concrete_Data.xls
#    - steel_strength.csv
#    - mechanical_material.csv

# 3. Verify datasets
python scripts\verify.py

# 4. Run the full pipeline
python main.py
```

## Outputs
All results saved to outputs\ after running main.py.
Trained models saved to models\ as .pkl files.
